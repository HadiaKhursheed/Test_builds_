1. **strip_light_board_display.ino** :- This is a prototype of a display board made by using WS2812B led strip with ESP8266. Its a 11 by 10 led display board. Currently 11 by 5 led display portion is working & can easily display text when we enter from our phone by connecting to its Wi-Fi.
2. **TM1637&Clock_display_combined.ino** :- This was the code I used when I wanted to make a comparison video of inspiration of clock display (TM1637) vs the clock display project I successfully made. This code combines functionality for a TM1637 display and a strip light digit display, integrating RTC and NTP for time synchronization.
3. **TM1637_starting_animation.ino** :- This code is for playing cool animation on TM1637 clock display & ESP8266. The animation can be used in any project with TM1637 as a loading animation.
4. **Turn_OnOff_LED_onWeb.ino** :- Through this code we can turn the LED on-off over the Wi-Fi through webpage without any physical switch.
